01 what the agent runs

  1. h5i browserExplore your app automatically

    Your agent can read pages, click, type, and extract data through compact snapshots.

  2. h5i websecTest HTTP requests directly

    Your agent can capture traffic, inspect and edit requests, replay them, and compare responses.

  3. h5i boxSandboxed workflow

    Sandbox the browser or the entire AI agent workflow, with configurable network and filesystem limits.

  4. h5i testKeep it fixed

    Replay a confirmed finding as a flow in CI, so a fixed issue stays fixed.

FAQ

Frequently asked questions

The short answers. The manual has the long ones.

What is h5i?
h5i is an open-source, agent-native workspace for secure web development. It provides browser and HTTP security testing, regression checks in CI, and configurable sandboxing. Its h5i-app framework, an Axum-based Rust framework, lets developers prove properties of their application logic in Lean 4.
Do I need to rewrite my app in Rust?
No. The browser, HTTP testing tools, and security regression tests work with existing web applications in any language. The application framework is optional, for teams that want to write and verify application logic in Rust. It ships as h5i-app, with its documentation and tutorials in the h5i repository.
Does a proof mean my entire app is secure?
No. A proof establishes a stated property of the verified logic under explicit assumptions. It does not establish that every route, authentication adapter, dependency, or deployment is correct. Testing and review are still needed at those boundaries.
Do I need to be a security expert to use h5i?
No. You tell your agent what to check in plain language, for example whether one user can read another user's orders. The agent explores the app in the browser, captures the requests behind each action, then edits and replays them to test the idea. Every request and response is recorded, so you, or a security reviewer later, can check the evidence behind a finding. Only test applications you own or are authorized to test.
Is h5i an automated vulnerability scanner?
No. h5i does not run a fixed list of checks against a URL and hand back a report. It gives your agent the tools a professional tester uses, and the agent decides what to try. Once a finding is confirmed, h5i test can replay it as a flow in CI, so a fixed issue stays fixed.
How does h5i compare with Playwright, Puppeteer, or Burp Suite?
Playwright and Puppeteer are the right choice when maximum website compatibility is the priority. Burp Suite is the right choice when an experienced tester wants the deepest workbench: an intercepting proxy, Scanner, Intruder, and extensions. h5i is for the case where your own AI agent runs the test end to end: one session drives the browser and records its traffic, and the agent edits, replays, and compares requests through a CLI built for it, inside a sandbox with a reviewable record. See the Burp Suite comparison.
Does h5i work on every website?
No. h5i works best for content-heavy websites and common browser interactions, but some browser APIs are not yet supported. For incompatible websites, you can run Chromium inside an h5i sandbox.
How is the agent contained?
The browser uses lightweight process isolation when available. To restrict the agent's other tools as well, sandbox the entire workflow and configure its network and filesystem policy; the options are supervised isolation, containers, and microVMs, and enforcement depends on the selected tier and host support. This limits what a misled agent can reach, but it does not prevent prompt injection: a tested application can still mislead the agent on a target you allowed.
Where do my credentials and data go?
Credentials stay out of the model. The agent references a named credential without reading its value, or a human takes control to log in, and the authenticated session continues without returning the password or cookie. h5i has no hosted service and stores its sessions locally. Browser traffic still goes to the websites you allow, and model traffic goes to your configured model provider.
