01 / Build and verify web applications

A Verifiable Web Framework

Build on Axum with a composable, kernel-based Rust architecture. Translate application logic into Lean 4 to verify critical properties, with optional GPU acceleration for supported workloads.

  • Kernel-based architecture

    Separate application logic from infrastructure so core behavior can be verified and optimized.

  • Formal verification

    Prove properties such as authorization, data isolation, and business logic correctness with Lean 4.

  • Optional GPU acceleration

    Run supported application kernels on GPUs while retaining CPU execution.

Development Infrastructure

From local development to security testing, h5i gives AI agents the tools to build, verify, debug, and test your applications. Its browser, HTTP, red-teaming, and CI tools also work with any existing web app.

FAQ

Frequently asked questions

The short answers. The manual has the long ones.

What is h5i?
h5i is an Axum-based Rust web framework for building applications and verifying core logic with Lean 4. Its CLI also provides browser, HTTP, recon, and CI/CD testing tools.
How do I build and verify a web app?
Start an h5i-app project with h5i app new. Write application logic in Rust kernels, extract it to Lean 4 with h5i app extract, check proofs with h5i app prove, and test proof sensitivity with h5i app mutate.
Can h5i-app kernels run on a GPU?
Yes. The Rust-CUDA backend runs shared Rust decision kernels on GPUs for suitable batch workloads. Lean proofs cover the extracted kernel logic; CPU/GPU behavior is checked separately with differential tests. See the GPU report.
Can I test an existing app without using h5i-app?
Yes. The browser, HTTP, recon, and security regression tools work with web applications in any stack. You do not need to migrate to the Rust framework.
Does a proof cover my entire application?
A proof establishes a stated property of the verified logic under explicit assumptions. Routes, authentication adapters, dependencies, and deployments still need testing and review.
