h5i Guides

Give a coding agent a box, get a reviewed patch back

Task-focused walkthroughs, each one a short numbered sequence with the commands that actually run. Start with the workflow overview for the shape of the loop, then pick the guide for the thing you are doing: reviewing somebody else's branch, keeping credentials out, bounding what an injected agent can reach, or making box creation cheap enough to do constantly.

Overview · Workflow

The loop: box, work, export, apply

The whole shape on one page. Copy the code into a disposable box, let an agent build and test and drive a browser inside it, then export a patch, a report and an execution receipt and decide what to take.
Guide · Review

Review a pull request in a box

Fetch a pull request head into a detached box with no host credentials, build and exercise it, then read a report whose first section is every destination the boundary refused.
Guide · Export

Export a reviewable patch from a box

Three files out of the output gate: a path-validated patch, a report of what ran, and a receipt of every observed execution. Then git apply --3way wherever you want it.
Guide · Security

Pass API tokens to a coding agent without leaking them

Keep the real key on the host. The box authenticates through a credential-injecting proxy, so a prompt-injected agent has no reusable token to steal.
Guide · Security

Contain a prompt-injected agent

Skip detection, which is low-recall by construction. Assume the injection worked, and write down in a profile exactly what the compromised agent is able to reach.
Guide · Credentials

Give a box your Claude Code config without your credentials

Your settings come with it; credential-shaped files are dropped by shape at any depth. How the seed works, and how to check what a box actually got.
Guide · Multi-runtime

Run Claude Code and Codex in separate boxes

Two runtimes on one task means two boxes and two credential sets, because a box holding both is a laundering path waiting for a prompt injection.
Guide · Receipts

Find out what actually ran in a box

Four commands for what a supervisor watched, what a proxy refused, and which grade of evidence each line came from. None of them needs the agent to cooperate.
Guide · Performance

Warm the dependency cache so boxes start fast

Populate a cache once in a box with no agent in it, keyed by lockfile digest, then every agent box mounts it read-only. A twenty-second box instead of a four-minute one.
