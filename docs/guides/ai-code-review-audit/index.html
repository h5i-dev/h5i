Review a pull request in a box

Reading a diff tells you what somebody wrote. Building and running the branch tells you what it does, and a detached box makes that the cheap option rather than the risky one.

By Koukyosyumei Reading time 5 min Tags Review · Pull requests · Containment
The gotcha up front. A box from --pr is detached: it gets a repository of its own, your repository is untouched after creation, and the inherited origin remote is dropped. apply and rebase refuse there. That is the point, not a limitation.

1. Fetch the pull request into a box

~/my-project
$ h5i box --pr 1234
  created box pr-1234 · detached · origin remote dropped

--pr takes a number, a #number, or a URL. It fetches refs/pull/<n>/head, pins it immutably, and needs only git. Nothing of your machine goes into the box: no SSH key, no GitHub token, no cloud credential.

2. Build and exercise it

~/my-project
$ h5i box shell pr-1234
box$ npm ci && npm test    # lifecycle scripts run in here
box$ npm run dev &
box$ agent-browser open http://localhost:3000
box$ exit

shell inherits stdio, so everything the session spawns is contained by the box rather than by remembering to wrap each call. Run an agent in here if you would rather it did the reading: claude or codex, scoped to one runtime's credentials.

3. Export and read the report

~/my-project
$ h5i box export pr-1234 --out ./review
$ head -12 ./review/report.md

# Denied egress
  telemetry.vendor.invalid:443   refused (not in net.egress)   x7

Seven refused connections from a branch whose description says it fixes a date-formatting bug is not something the diff would have told you.

4. Clean up

~/my-project
$ h5i box rm pr-1234
$ h5i box gc          # reclaim finished workspaces
An empty denied-egress section is not always good news. At isolation=microvm the guest's netstack drops packets without reporting them, so a microvm receipt carries no egress summary at all. Check which tier produced the report.

FAQ

Do I need GitHub credentials inside the box?

No. Fetching the head uses the access you already have, host-side. Nothing enters the box: no SSH key, no GitHub token, no model API key, no cloud credential.

What does detached mean here?

The box gets a repository of its own, your repository is neither read nor written after creation, and the inherited origin remote is dropped so the box arrives holding no network handle. apply and rebase refuse and point at export.

Can an agent do the review inside the box?

Yes, and it is the ordinary case. h5i box shell drops Claude Code or Codex in with the branch checked out, scoped to one runtime's credentials, under the same policy as everything else.
