05 / Technical depth

Confidence comes
with a chain of evidence.

BOUNDED EXECUTION

Set the agent’s reach.

Optional boxes constrain files, network access and runtime. Receipts distinguish host observations from box claims.

POLICY → EXECUTION → RECEIPT

Network enforcement depends on the tier. Only microvm provides a separate guest kernel.

CHECKED PROPERTIES

Tie proofs to the logic.

Charon and Aeneas extract Rust into Lean. Verification gates check proof builds, extraction drift, axioms and mutations.

RUST → LEAN → VERIFICATION

The specification, translation and runtime assumptions define the guarantee.

06 / Why h5i

Built for AI to operate.
Built for humans to oversee.

h5i’s advantage is the connection between an agent-friendly CLI and a dashboard for human understanding and control.

DESIGNED FORWHAT THIS MAKES POSSIBLE
The AI doing the workRun focused commands and use compact results to choose the next test.
The human overseeing itFollow actions, inspect findings, and take control of or stop the browser.
Their shared workflowConnect the agent’s actions to the session and evidence you review.
The product value: AI can work through the tests, and you can understand and manage what it does.
