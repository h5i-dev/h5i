03 / The product

h5i: Build, Verify, and Hack Web Apps

01 / BUILD

Composable Rust kernels

Axum-based framework with a separate kernel for application decisions and GPU support for suitable batch workloads.

02 / VERIFY

Lean 4 proofs

Extract Rust logic, prove critical properties, and test proof sensitivity with mutations.

03 / HACK

Agent-led red-teaming

Explore any web app, replay HTTP requests, and turn confirmed findings into CI tests.

HOW IT COMES TOGETHER

h5i unifies building, verification, and red-teaming

A shared CLI and local dashboard connect the work, with sandboxed agent workflows for security testing.

06 / Hack

Red-team any web application
