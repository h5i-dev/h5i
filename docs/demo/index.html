Proven, not patched.

h5i extracts the kernel of a Rust web app into Lean 4 and proves its rules. In this board app, the theorem authorized shows that every write the kernel makes is allowed. Only a post's author or a moderator can delete it, whatever the request.

$ cargo add h5i-app Board tutorial Manual

The Rust function and Lean theorems on screen come from examples/app/board. The terminal output, the attacker, and their requests are illustrations. The proof covers the kernel's writes. It does not cover HTTP routes that bypass the kernel.
