# Demo film master

`h5i-demo.mp4` is the rendered demo film (1080p, 52 s, AAC audio), kept here
as the source copy of what is on YouTube (https://youtu.be/eHOLi1kxWEo).
It sits outside `docs/` so GitHub Pages does not publish or serve it; the site
embeds the YouTube player instead.

To change the film, edit and rebuild it with `docs/demo/film/build.sh`
(see `docs/demo/README.md`), replace this file, and upload the new MP4 to YouTube.
